# Carpeta de pruebas

Esta carpeta queda reservada para pruebas automatizadas del proyecto.

## Estado actual

El repositorio no contiene aun una suite automatizada formal para backend o frontend. Por eso se deja esta carpeta como punto de organizacion para futuras pruebas.

## Estructura sugerida

- backend/: pruebas unitarias e integracion de controladores, rutas y servicios.
- frontend/: pruebas de componentes, flujos de pagina y validaciones de UI.
- fixtures/: datos de prueba reutilizables.

## Prioridades recomendadas

1. Pruebas de autenticacion.
2. Pruebas de endpoints criticos de usuarios, medicos y citas.
3. Pruebas de renderizado y navegacion por rol en frontend.
